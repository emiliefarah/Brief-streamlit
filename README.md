# Tableau de bord — Qualité du référentiel TVA

Projet réalisé dans le cadre de ma formation Data Analyst.

## Objectif
Analyser la qualité d'un référentiel de 10 000 numéros de TVA et identifier les anomalies nécessitant une action.

## Fonctionnalités
- Indicateurs de qualité des données
- Graphiques interactifs avec Plotly
- Filtres par pays, canal et période
- Analyse des résultats VIES
- Liste des numéros à traiter avec export CSV

## Technologies utilisées
Python · Pandas · Streamlit · Plotly
